# 魔法烘焙坊

入口 `/game/bakery/`，整合至遊戲百寶箱、站內搜尋與遊戲數。純 Vue、TypeScript、CSS、Pointer Events 與 Web Audio，沿用共用頁首頁尾及 GitHub Pages base-path 處理，無新增依賴、登入或付款。

## 現有操作

- 獨立入口直接選六個章節或今日營業，所有練習固定最高難度。
- 第一章自動混合形狀及口味說法，數量與形狀每題改變，連續配方不會相同。單盒烤盤包含三種形狀的備用餅乾，避免從烤盤就猜出答案。
- 桌面左側顯示實際有限數量的餅乾，右側同時顯示所有盒子。每次拖一片，可放入任意盒子、盒間搬動或放回烤盤，最後檢查整張訂單。
- 整個盒子都接受放入；空盒可點範圍至少 100px 高，清楚標示「放回烤盤」的區域至少 58px 高。非法／過滿／來源失效／拖到區域外的操作不扣庫存，Escape 可取消。
- 手機上烤盤在盒子上方，主要用「先點餅乾，再點盒子」，保留垂直捲動；選取提示、取消及拿回操作固定在底部安全區上方。鍵盤同樣可以選取與放入。
- 補貨小幫手顯示需求與原有庫存，學生自行判斷缺量，逐片烤出，再按「烤好了」檢查。可多烤、拿回新烤餅乾；原有庫存保持不動。
- 大師章節直接依口味烤餅乾，沒有模具，手動按「烤好了，開始裝盒」後再分裝。
- 沒有輔助工具區、難度選單或訂單說法選單。右上提供自動朗讀、顯示算式與小喇叭靜音鍵；算式只在完成後顯示。
- 今日營業含兩盒綜合、三盒巧克力及六片草莓平均分兩盒，全部交貨才記錄一次營業完成。

## 音效

`sound.ts` 即時合成六種低音量、短促的音效：拿取、放入、拿回、烘烤、成功、溫和重試。互動前不建立 AudioContext；靜音直接歸零主音量並停止排程新音，重新開啟時恢復。偏好使用 `cactusbeing-bakery-sound`，獨立於完成次數。無外部音檔或背景音樂，裝置不支援音效時仍可遊玩。語音取決於裝置安裝的瀏覽器聲音。

## 程式驗證

`npm run test:bakery`：

- 3,780 組六章／三階段／七種配方的生成器回歸驗證；正式入口只用最高階段。
- 900 組固定種子的學徒訂單，檢查形狀／口味措辭與數量變化，包含常數亂數來源也不能讓連續隨機配方相同。
- 1,500 次固定種子的任意搬動，逐次驗證各形狀總量守恆、庫存非負，另檢查放入任意盒、拿回、無效／過滿／來源失效的操作不變動庫存。
- 烘烤少量、多量、錯誤口味、漏盒、錯形狀、不平均及生日派對配方檢查。
- 音效的延後初始化、六種合成音、靜音不排程新音、不支援時退化與卸載關閉資源。

`npm run build`：烘焙坊、聊天傳接球、教檢測試，Vue 型別檢查，Vite 建置，公開 URL／素材參照及既有內容相容性檢查。

## 瀏覽器驗證

使用共用 default browser 的真實拖曳與鍵盤操作。檢查烤盤→指定盒子、盒間搬動、放回、區域外與 Escape 取消、整張訂單驗證、除法錯誤重分、六章與生日派對、手機點選後捲動與固定操作列、放入與放回範圍、右上按鈕、無模具烘烤及自動混合措辭。

音效另外以真實 AudioContext 觀察已啟動狀態、主音量及音符排程，檢查靜音與重新啟用。未宣稱測量實際喇叭輸出。桌面 1440px、平板 768px、手機 390px 畫面證據保留在 `.impeccable/review/`，不納入公開網站。測試恢復原本的完成次數。
