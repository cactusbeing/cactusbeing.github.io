## 答案來源與重製

可檢閱的逐頁答案來源位於 `scripts/materials/grade7-math-answers.json`。
每份來源包含原始 PDF 的 SHA-256；原學生版一旦更動，產生器會停止，避免沿用不相符的解答。
純數值題使用精確分數運算產生最簡答案。線對稱方格直接鏡射原 PDF 的已塗色方格，
對應點按原軸座標反射；三視圖答案以原題視角畫出向下對齊的方格圖。

```sh
python3 -m venv /tmp/grade7-teacher-env
/tmp/grade7-teacher-env/bin/pip install -r scripts/materials/requirements.txt
/tmp/grade7-teacher-env/bin/python scripts/materials/verify-grade7-math.py
/tmp/grade7-teacher-env/bin/python scripts/materials/build-grade7-teacher.py --output /tmp/grade7-teacher-output
```

預設使用 macOS 系統的 Arial Unicode 字型；其他環境可用 `--font /path/to/font.ttf`
提供涵蓋繁體中文、數學符號與上標字元的字型。PDF 只嵌入使用到的字形，網站不需要 Python 或字型原檔。

## 上架方式

使用 `./upload-materials /tmp/grade7-teacher-output/*_教師版.pdf`，選擇數學／國中資源班。
`teacherFiles` 對照使教師版與原學生版共用教材卡片及教材計數，增加附 PDF 圖示的「教師版」下載入口。
學生版、PPTX 與 DOCX 也用檔案圖示下載，保留 44px 觸控範圍；
預覽按鈕展開該教材後，可另選「在新分頁開啟 PDF」。
`_教師版.pdf` 與 `-teacher.pdf` 視為同一學生教材的教師版本。
後續上傳可編輯版或把可編輯主檔補成 PDF 時，工具會保留教師版關聯。
教師版同名、內容重複、班別不符、沒有學生教材或已存在另一教師版，都會在寫入前拒絕。

## 本次檢查

- 逐頁對照原講義 113 頁，包含選擇題、填答題、計算題及作圖題。
- 使用 SymPy 獨立檢查 425 組數值等式、代數恆等式與已給解的方程式。
- 另依原講義題值檢查 12 題科學記號互換，涵蓋僅列答案的換算題。
- 只要求列式的兩頁共 8 個方程式寫法（含一個等價寫法），保留為列式答案，不強迫求解。
- 檢查三視圖作圖格數與指定觀察方向；第 7 頁三圖由同一高度模型投影核對。
- 確認教師版僅有 41 頁解答；所有原學生版 SHA-256 維持不變，113 頁均有對照答案。
- 檢查解答文字均落在頁面範圍內，並檢視解答附錄的實際渲染與圖形。
- 以瀏覽器檢查 320、375、768、1440px 寬度；國一數學及生活管理的圖示下載列均無換行或橫向溢出，觸控高度至少 44px。
- 十一份教師版下載均回傳 HTTP 200 與有效 PDF 檔頭；預覽展開後保留另開 PDF 的入口。

上架及網站建置檢查由 `upload-materials` 的完整 build 執行，包含教師版配對、學生版主檔轉換、
班別與重複版本拒絕、原公告隱藏狀態保留，以及正式產物中教師版下載檔確實存在的檢查。
