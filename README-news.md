# 最新消息與小站公告

首頁顯示最新 6 則消息，分類篩選先查完整清單，再限制顯示筆數。
採緊湊列表，預設只顯示標題、分類與日期，可按「顯示摘要」展開說明。
`/news.html` 提供所有消息，每次載入 12 則。所有消息以台北日期判斷，未到日期或
`hidden: true` 的項目不公開。文章從既有文章資料自動加入，沿用原始發布日期。

## 新增消息

編輯 `src/content/updates.json` 的 `entries`，例如：

```json
{
  "id": "new-feature-20261108",
  "date": "2026-11-08",
  "category": "site",
  "title": "功能名稱上架",
  "summary": "用一句話說明新增內容與用途。",
  "href": "/tool.html"
}
```

分類：`materials` 教材、`games` 遊戲、`articles` 文章、`exam` 教檢、`site` 其他。
網站更新歸在「其他」，可在公告標題前加上 `[網站更新]`。
`id` 不得重複，`href` 使用站內連結；標題直接開啟對應頁面，不必另寫公告文章。
若手動消息的 `href` 與文章一致，會優先採用手動消息，不會重複列出該篇文章。

教材使用 `./upload-materials <files...>` 後會自動產生消息。
標題統一為 `教材類別「教材名稱」上架`，例如 `生活管理「護牙大冒險」上架`。
檔名開頭重複的分類與分隔符，以及可編輯版結尾會自動移除。
同一教材的 PDF／PPTX／DOCX 合為一則；後補格式不另發一則，也不變更原始公告日期。
自動產生的消息摘要會同步更新格式，手寫摘要則保留。教材移除或分類下架後，
對應教材消息會從前台隱藏；清理舊資料時可一併刪除那則消息。

## 小站公告：置頂、留言或兩者並用

同一檔案的 `notice` 控制公告：

```json
{
  "enabled": true,
  "heading": "小站公告",
  "message": "想對訪客說的話，可使用換行。",
  "featuredId": "exam-108-115",
  "expiresAt": "2026-12-31"
}
```

- `featuredId`：填入 `entries` 既有消息的 `id`，將該消息置頂。只想留言時設為 `null`。
- `message`：留言文字；只想置頂時留空字串。可同時留言與置頂。
- `expiresAt`：到期日當天仍顯示，隔天公告及置頂失效；原消息仍保留並按日期排序。
  設為 `null` 表示不自動到期。
- `enabled: false`：停用公告與置頂，不刪除歷史消息。
- 留言可加 `href` 與 `linkLabel`，提供站內延伸連結。

首頁與所有消息頁將留言放在消息區上方、置頂放在清單內。
其他使用部落格側欄的頁面沿用精簡小站公告，讀取同一份設定。
沒有留言及有效置頂時，公告區自動隱藏。

## 驗證

```sh
npm run test:news
npm run test:materials
npm run build
```

正式 build 會驗證消息格式、日期、重複 ID、置頂設定及目的頁面是否存在。
上架工具遇到建置失敗時會連同消息一起還原；`--commit` 也會納入這次產生或修改的消息。
