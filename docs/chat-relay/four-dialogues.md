# 四組連續對話修正版

本檔列出所有節點、選項、NPC 反應、完整回饋與合法出口。選擇後先呈現 NPC 反應；一般回應只顯示短提示，需要調整時才呈現完整提醒。結束頁依實際選擇整理技巧，自然收尾不算失敗。

## 修改前後

| 項目 | 修改前 | 修改後 |
| --- | --- | --- |
| 畫畫 | 未提到風吹也能選「被風吹喔」 | A4-wind／A4-sketch 分流，僅前者能提到風吹 |
| 模型 | 沒提拆模型也能選「先別拆啦」 | C5-tired／C5-dismantle 分流 |
| 看書開場 | 「現在方便聊一下嗎」 | 「你在看海洋動物喔？可以一起看嗎？」 |
| 模型建議 | 在底下加紙板，未必能固定屋頂 | 提議扶著屋頂等膠乾，仍保留太早給建議後的修復 |
| 模型同理 | 「難怪那麼悶」 | 「都快好了又倒，真的很氣耶」 |
| 網路交友 | 同時決定好友與 LINE | 先問遊戲好友，聊過遊戲才問 LINE，可各自拒絕 |
| 教學回饋 | 每句都顯示完整說明 | NPC 優先、一般回覆短提示、需提醒才展開、情境結束整理 |

## 一起畫畫（classroom-drawing）

場景：美術課，你和小莓共用一張桌子。你的手臂靠近她的畫紙，她畫線時碰到了你。

### start

對方／畫面：有點擠耶，我手不好動。

1. 玩家：喔，我移過去一點。這樣可以嗎？
   - NPC／畫面：可以了，謝啦。你在畫什麼？
   - 當下顯示：你有移開，也問她這樣行不行。
   - 完整回饋：你移出了空間，也確認小莓現在好不好畫。
   - 下一節點：`A3`

2. 玩家：喔，好。
   - NPC／畫面：你可以再移一點嗎？我的筆還是會碰到你。
   - 當下顯示：她還需要多一點空間。
   - 完整回饋：你有回應她，但位置還沒改變。可以再移一點。
   - 下一節點：`A2`

3. 玩家：才靠一點點，有什麼關係？
   - NPC／畫面：可是我真的不好畫耶。
   - 當下顯示：你覺得距離還好，小莓卻不好活動。現在還來得及調整。
   - 完整回饋：你覺得距離還好，小莓卻不好活動。現在還來得及調整。
   - 下一節點：`A2`

### A2

對方／畫面：我的手還是不好動。

1. 玩家：好，我移過去。這樣呢？
   - NPC／畫面：這樣可以了。你在畫什麼？
   - 當下顯示：你聽懂後，願意調整位置。
   - 完整回饋：聽到她再說一次，你願意調整，兩個人就能繼續畫。
   - 下一節點：`A3`

2. 玩家：那我換到旁邊的空位畫。
   - NPC／畫面：好啊，這樣比較放得下。
   - 當下顯示：換個位置，也能讓彼此舒服。
   - 完整回饋：你找到另一個位置，讓彼此都有足夠的空間。
   - 下一節點：`end-draw`

3. 玩家：一下而已，繼續畫啦。
   - NPC／畫面：我想自己畫，先不要靠過來。
   - 當下顯示：小莓已經說不想再靠近。這時要停下來，留出她需要的空間。
   - 完整回饋：小莓已經說不想再靠近。這時要停下來，留出她需要的空間。

   - NPC／畫面：我剛剛畫樹也歪掉，最後直接改成被風吹。

   - 當下顯示：你說明想先專心。
   - 完整回饋：你說明自己想先專心，也留下之後分享的機會。
   - 下一節點：`end-draw`

   - 當下顯示：各自畫畫，也很自然。

   - 完整回饋：你把她的經驗接回自己的畫，聊完後也能繼續做事。
